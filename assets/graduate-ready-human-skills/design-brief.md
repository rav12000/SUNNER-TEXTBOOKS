# Graduate-Ready Human Skills Design Brief

## Product format
A professional commercial textbook/workbook hybrid for institutional buyers and student users. The interior should feel credible for university and college adoption while remaining practical, warm and easy to use.

## Target buyers and users
| Audience | Need | Design implication |
|---|---|---|
| Employability teams | Ready-to-run program resource | Clear module structure and portfolio outputs |
| Student services/orientation | Practical transition support | Welcoming tone, simple activities, strong signposting |
| Tutors/facilitators | Session-ready learning design | Visible timings, debrief prompts and worksheets |
| Students | Useful tools for placements and work | Plenty of writing space, templates and examples |

## Recommended book structure
1. Front matter and wellbeing note
2. How to use this textbook
3. Graduate readiness self-assessment
4. Eight chapters
5. Portfolio template
6. Assessment tasks and rubric
7. Teaching plan and facilitator notes
8. Appendices and templates
9. Back cover/product copy

## Page design system
| Element | Treatment |
|---|---|
| Chapter opener | Full-width title, chapter purpose, learning outcomes |
| Scenario | Light shaded box with icon |
| Core concept | Standard body text with callout quotes |
| Key terms | Two-column table or glossary card |
| Reflection | Worksheet box with generous writing space |
| Group activity | Step-by-step numbered card |
| Portfolio task | Distinct accent colour and checklist |
| Facilitator note | Small shaded sidebar, clearly marked |
| Assessment option | Formal table format |

## Accessibility requirements
- Use clear heading hierarchy.
- Maintain high contrast and readable font size.
- Avoid relying on colour alone to communicate meaning.
- Ensure tables have header rows.
- Keep worksheet instructions plain and concise.
- Provide alt-text guidance for icons and diagrams.

## Suggested trim and production
- A4 PDF workbook for institutions.
- US Letter export option for international buyers.
- Editable DOCX/Google Docs facilitator version.
- Slide deck in 16:9 format.
