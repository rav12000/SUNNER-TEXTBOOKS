# Graduate-Ready Human Skills Publication Roadmap

## Current stage
The core manuscript and production assets exist in draft form. The next objective is to move from content creation into review, design, pilot and launch.

## Stage 1: Editorial consolidation
| Task | Owner | Output |
|---|---|---|
| Review manuscript for repetition and flow | Editor | Edited manuscript |
| Confirm chapter titles and terminology | Author/editor | Style sheet |
| Replace or approve placeholders | Author + institution | Localised manuscript |
| Check Australian English consistency | Editor | Clean copy |

## Stage 2: Institutional and compliance review
| Task | Owner | Output |
|---|---|---|
| Map chapters to graduate attributes | Employability reviewer | Completed mapping worksheet |
| Verify academic integrity and AI-use references | Policy reviewer | Policy notes |
| Verify placement and confidentiality language | WIL/placement reviewer | Required edits |
| Review safeguarding and referral language | Wellbeing reviewer | Approved support language |

## Stage 3: Design and production
| Task | Owner | Output |
|---|---|---|
| Build layout system | Designer | Sample chapter design |
| Convert worksheets into workbook pages | Designer | Worksheet pack PDF |
| Design facilitator slides | Designer | 16:9 slide deck |
| Export accessible PDF | Designer/accessibility reviewer | Tagged PDF or remediation notes |
| Prepare sample chapter | Marketing/designer | Preview PDF |

## Stage 4: Pilot
| Task | Owner | Output |
|---|---|---|
| Select pilot group | Program lead | Pilot plan |
| Deliver one orientation workshop or 2-3 modules | Facilitator | Delivery notes |
| Collect student and facilitator feedback | Program lead | Evaluation summary |
| Revise content and assets | Author/editor/designer | Release candidate |

## Stage 5: Launch package
| Asset | Status needed before launch |
|---|---|
| Student textbook/workbook | Final PDF and source file |
| Facilitator guide | Final PDF/source file |
| Slide deck | Editable and PDF versions |
| Worksheet pack | Print and digital versions |
| Institutional adoption pack | Final buyer-facing PDF |
| Sample chapter | Public preview version |
| Product page copy | Approved website copy |
| Licence terms | Legal/commercial approval |

## Versioning recommendation
Use semantic draft labels until publication:
- `v0.1` — AI-assisted content draft
- `v0.2` — editorial working draft
- `v0.3` — institutional review draft
- `v0.4` — designed pilot draft
- `v0.5` — pilot revision
- `v1.0` — commercial release

## Immediate next actions
1. Assign reviewers for editorial, employability, wellbeing, accessibility and legal/compliance review.
2. Convert the worksheet pack into a designed workbook layout.
3. Create a branded sample chapter PDF.
4. Pilot a 45-90 minute orientation workshop.
5. Use pilot feedback to create the release candidate.
