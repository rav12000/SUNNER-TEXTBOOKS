# Graduate-Ready Human Skills Packaged Preview

## Purpose
This folder contains static, design-ready preview pages for the next commercial packaging stage of **Graduate-Ready Human Skills**.

## Files
- `product-page.html` — buyer-facing product page draft.
- `sample-chapter.html` — sample chapter preview with worksheet section.
- `styles.css` — print-aware visual styling for the preview pages.

## How to review locally
Open either HTML file in a browser, or serve the folder with:

```bash
python3 -m http.server 8000 --directory packaged/graduate-ready-human-skills
```

Then visit:

- `http://localhost:8000/product-page.html`
- `http://localhost:8000/sample-chapter.html`

## Production notes
- These files are a design prototype, not the final website build.
- Copy should remain aligned with the manuscript, marketing copy and institutional adoption pack.
- Final launch should confirm licence terms, pricing, support contacts, accessibility and legal review.
